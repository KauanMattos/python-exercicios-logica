# 🐍 Exercícios de Lógica em Python

Repositório com exercícios práticos de lógica de programação em Python, focado no desenvolvimento de habilidades com estruturas condicionais, validações e resolução de problemas.

---

## 📚 Conteúdos abordados

- Estruturas condicionais (`if`, `elif`, `else`)
- Validação de dados de entrada
- Operações matemáticas
- Média simples e média ponderada
- Tratamento de erros (ex: divisão por zero)

---

## 💻 Exercícios implementados

### 📌 Sistema de Notas
- Entrada de notas
- Validação entre 0 e 10
- Cálculo de média
- Classificação:
  - Aprovado
  - Recuperação
  - Reprovado

---

### 📌 Análise de Crédito
- Entrada de salário e parcela
- Cálculo de comprometimento de renda
- Regra de aprovação:
  - Até 20% → aprovado
  - Acima de 20% → negado

---

### 📌 Média Ponderada
- Três avaliações com pesos diferentes
- Cálculo correto da média ponderada
- Classificação:
  - Aprovado
  - Reprovado

---

### 📌 Calculadora
- Operações básicas:
  - Adição
  - Subtração
  - Multiplicação
  - Divisão
- Tratamento de divisão por zero

---

Praticar lógica de programação e consolidar conceitos fundamentais para desenvolvimento em Python.
